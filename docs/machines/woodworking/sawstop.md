## SAFETY FIRST (READ BEFORE USE)

Brake System: This saw is equipped with an automated brake that stops the blade on contact with skin. Never disable this safety feature.  
Eye/Ear Protection: Always wear safety glasses and hearing protection.  
Material Prep: Ensure wood is free of nails, staples, or excessive moisture (which can trigger the brake).  
Push Sticks: Always use a push stick for rips narrower than 6 inches.  

## BASIC OPERATION


### Power-On Sequence:

Turn on the Main Power switch.  
Wait for the system self-test (Green light should be solid).  
Pull the Start/Stop paddle to start the blade.  

### Adjustments:

Blade Height: Use the front handwheel to set the blade roughly 1/8" above the material.  
Blade Tilt: Use the side handwheel to set the desired bevel angle.  

## TROUBLESHOOTING

Red Light Flashing: The brake system has detected an error or a triggered cartridge. Power down and inspect.  
Blade Won't Start: Check that the thermal overload reset button has not tripped and that the blade is not touching the guard.
