## SAFETY FIRST (READ BEFORE USE)

Automated Motion: This printer operates at very high speeds; keep the enclosure closed during operation to avoid injury.  
Heat Hazard: The nozzle and heatbed reach high temperatures; allow the machine to cool before removing parts or performing maintenance.  
Ventilation: Ensure proper airflow, especially when printing materials that emit fumes.  
Supervision: Monitor the first layer of every print to ensure proper adhesion and prevent "spaghetti" failures.  

## BASIC OPERATION


### Power-On Sequence:

Flip the power switch on the rear of the unit.  
Wait for the system to initialize and the touch screen to load.  
Ensure the build plate is clean and properly seated on the magnetic base.  

### Running a Job:

Slice your model using Bambu Studio.  
Send the file via Wi-Fi or load it onto the MicroSD card.  
Select the file from the "Files" menu and press Print.  
The machine will perform a self-calibration and bed-leveling sequence before starting.  

## TROUBLESHOOTING

First Layer Issues: Check that the correct build plate type is selected in the slicer and that the plate is clean.  
Filament Jam: Inspect the extruder and nozzle for clogs; use the "Unclog" utility in the maintenance menu.  
Connection Error: Restart the machine and check your network settings if the printer does not appear in the software.
