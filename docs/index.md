# Welcome to the IUP Steamshop

The **IUP Digital Fabrication Lab** (DigiLab / Steamshop) is a hands-on workspace for students, faculty, and staff to design, prototype, and build using professional-grade equipment — from 3D printers and laser cutters to CNC mills, welders, and robotic arms.

This site is your central reference for machine operating procedures, shop guidelines, and active student projects.

---

!!! tip "New here? Start with onboarding."
    Before using any equipment unsupervised, read the [Onboarding Guide](guidelines/onboarding.md), the [Safety Guidelines](guidelines/safety.md), and the [Code of Conduct](guidelines/conduct.md).
